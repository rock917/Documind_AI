How it works

  1. UploadPDF, Word, ODT or RTF. Scanned PDFs are read with OCR first.
  2. Check every clause typeA Legal-BERT model fine-tuned on CUAD, a set of 510 expert-labelled contracts, looks for each clause type and also learns when a clause is not there.
  3. Review the evidenceSee the passage highlighted on its page, its score against the threshold, and download everything as JSON.

Know the limits

  • It finds about 81% of the clauses that are really there, so "not found" is a strong hint, not proof. Check the page.
  • Scores are raw model scores compared with a threshold. They are not probabilities.
  • Handwriting is not supported, and scans can contain recognition errors.
  • Answers in Ask mode are written by an AI model from retrieved excerpts. Check the highlighted page before relying on them.
  • This is a research and portfolio project, not legal advice.

Scanned PDFs are read with OCR, which is slower and can contain recognition errors. Ask-a-question mode sends only the passages it needs to Groq, and only after you tick a box each time.
